# 자격증 공식 API 직접 조회

2026-11-10 결정: 작품 규모와 관리 난이도를 고려하여, 현재 화면의 자격증 정보는 Supabase 사전 수집 대신 공식 API에서 조회합니다.

```text
PLSAi 웹 화면 → Python FastAPI → 공공데이터 공식 API
```

- 목록: `/api/items`
- 종목 상세: `/api/details?jmcd=1320`
- 시험일정: `/api/schedules?jmcd=1320&year=2026&category=T`
- API 키는 `.env`의 `DATA_GO_KR_API_KEY`를 서버에서만 읽습니다.
- 정상 응답은 서버 메모리에 5분간 캐시합니다. 최대 256개 요청 조합을 보관하며 재시작하면 초기화됩니다.
- 조회 실패는 재시도 안내로, 정상 빈 응답은 제공 정보 없음으로 구분합니다.
- 목록의 자격구분 코드를 일정 요청에 전달합니다. 필기·실기 접수기간, 시험기간, 발표일을 표시하며 미제공 날짜는 임의로 채우지 않습니다.
- 기존 원문 응답의 로컬 저장·응답 검증·재시도 로직은 재사용합니다. 자격증 조회 과정에서 Supabase에는 저장하지 않습니다.

현재 카테고리 필터·검색·카드 배치·관심 항목 상세 화면은 이 조회 결과를 사용합니다. 프로필·관심 목록·개인 일정은 아직 localStorage에 저장합니다. 공모전 예시·AI 추천·학사일정 자동 조회는 이 API로 제공되는 기능이 아니며 별도 연동 대상입니다.

기존 Supabase 테이블·수집 CLI·`/api/v1/certifications` 계열 DB 조회 API는 보존하지만, 현재 웹 자격증 조회에서는 사용하지 않습니다. 이전 Supabase 사전 수집 설명은 과거 구성 기록입니다.

# SpecSignal 프로젝트 소개

작성 기준: 2026-09-29

## 1. 프로젝트 개요

**SpecSignal은 대학생이 자격증과 대외활동 정보를 탐색하고, 자신의 학사일정과 준비 가능 시간을 고려해 도전 계획을 세울 수 있도록 돕는 반응형 웹 프로젝트입니다.**

자격증 정보를 찾는 과정에서 끝나지 않고, 관심 항목을 모으고 준비할 일정을 선택하여 개인 캘린더로 관리하는 경험을 목표로 합니다. PC·태블릿·모바일 브라우저에서 사용할 수 있도록 구성하며, 현재는 공식 자격증 API 연동과 주요 사용자 흐름을 구현한 개발·시연 단계입니다.

## 2. 기획 배경과 해결하려는 문제

대학생이 자격증이나 공모전을 준비할 때에는 여러 기관의 공고를 찾아보고, 접수일과 시험일을 확인한 뒤 학교 시험기간과 겹치지 않는지 직접 비교해야 합니다. 관심 있는 활동을 발견해도 실제로 준비할 시간이 충분한지 판단하기 어렵고, 접수 마감을 놓칠 수도 있습니다.

SpecSignal은 이러한 과정에서 다음을 지원하고자 합니다.

- **정보 탐색:** 자격증 목록·상세정보·시험일정을 한곳에서 확인합니다.
- **개인별 판단:** 전공, 목표 직무, 관심 분야와 준비 가능 시간을 추천 조건으로 활용합니다.
- **일정 계획:** 학교 일정과 도전 일정을 함께 확인하여 준비 계획을 세웁니다.
- **후속 행동:** 관심 저장, 일정 등록, 알림 확인으로 탐색 이후의 행동을 연결합니다.

## 3. 주요 대상 사용자

- 전공이나 희망 직무에 맞는 자격증을 찾는 대학생
- 학교 수업·시험과 자격증 준비를 병행하려는 학생
- 관심 있는 공모전과 접수 마감을 정리하고 싶은 학생

## 4. 주요 기능과 현재 구현 상태

| 기능 | 제공 내용 | 현재 상태 |
|---|---|---|
| 자격증 탐색 | 전체 목록, 검색, 자격구분·직무분야 필터, 상세정보, 연도별 시험일정 | 공식 API 연동 구현 |
| 나에게 맞는 자격증 | 프로필과 종목명·직무분야 비교 | 키워드 필터 구현. AI 추천이나 응시자격 판정은 아님 |
| 개인 캘린더 | 일정 추가·수정·삭제, 월 이동, 날짜별 일정 확인 | 구현 |
| 관심 목록 | 데모 항목 저장·해제, 상세 확인, 일정 등록 연결 | 데모 항목 기반 사용자 흐름 구현 |
| 프로필 | 학교·전공·목표 직무·관심 분야·공부시간 설정 | 브라우저 내 저장 구현 |
| 학사일정 | 직접 입력, 조회 결과 확인·수정 흐름 | 직접 입력 및 예시 결과 사용. 공식 학교 검색은 미연동 |
| AI 맞춤 추천·챗봇 | 대화 입력, 추천 카드, 준비기간 및 학교 일정 비교 | 예시 항목과 규칙 기반 데모. 실제 LLM 미연동 |
| 공모전 탐색 | 목록, 필터, 상세 확인 | 가상 공모전 데이터 사용 |
| 알림 | 등록 일정의 알림 시점, 관심 공모전 마감, 최근 추천 확인 | 웹 화면 내 표시. 외부 발송·백그라운드 알림 미구현 |
| 반응형 화면 | 화면 너비별 배치, 접이식 메뉴, 모바일 입력·팝업 | 구현 |

공식 자격증 탐색의 실정보와 추천·공모전의 예시 정보는 구분해야 합니다. 예시 공부기간과 날짜는 실제 준비기간이나 공식 일정으로 보장하지 않습니다.

## 5. 대표 사용 흐름

1. **프로필 설정:** 학교, 전공, 관심 분야, 목표 직무와 하루 공부 가능 시간을 입력합니다.
2. **정보 탐색:** 공식 자격증 목록에서 검색·필터를 사용하고 상세정보와 시험일정을 확인합니다.
3. **개인 일정 관리:** 확인한 날짜를 개인 캘린더에 직접 등록하고 학교 일정과 함께 살펴봅니다.
4. **추천 흐름 체험:** 데모 추천 카드에서 추천 이유를 확인하고 관심 항목을 저장합니다.
5. **일정 등록:** 데모 카드의 일정 등록 창에서 날짜를 확인·수정하고 알림 시점을 선택합니다.
6. **진행 확인:** 홈 캘린더와 알림 패널에서 다가오는 일정을 확인합니다.

관심 저장과 일정 등록은 별도 동작입니다. 항목을 저장하거나 추천받는 것만으로 개인 캘린더에 일정이 추가되지는 않습니다.

## 6. 기술 구성

| 영역 | 사용 기술·역할 |
|---|---|
| 화면 | HTML, CSS, JavaScript로 대시보드와 반응형 UI 구성 |
| 서버 | Python HTTP 서버에서 웹 파일과 API 응답 제공 |
| 외부 정보 | 공공데이터 API를 통한 국가자격 목록·상세·시험일정 조회 |
| 사용자 설정 | 브라우저 localStorage에 프로필·일정·관심 항목 등 저장 |
| 디자인 | Figma 디자인을 참고한 화면과 SVG 자산 사용 |
| 검증 | Python unittest, Playwright를 이용한 Edge 브라우저 자동화 |

브라우저는 같은 서버의 API를 요청하고, Python 서버가 외부 자격증 API를 호출합니다. 외부 API 키는 서버에서만 읽습니다. 사용자 입력은 현재 브라우저에 저장되므로 다른 기기나 브라우저와 자동으로 공유되지 않습니다.

주요 파일 구성은 다음과 같습니다.

```text
SpecSignal_app/
├─ src/
│  ├─ web/                 # 화면, 스타일, JavaScript, HTTP 서버
│  └─ certification/       # 국가자격 API 조회·응답 처리
├─ tests/                  # 단위 테스트와 브라우저 검증
├─ docs/                   # 프로젝트 소개·설계 결정·구현 기록
├─ requirements.txt        # 웹 실행 의존성
├─ requirements-dev.txt    # 개발·검증 의존성
└─ start-web.cmd           # Windows 웹 서버 실행
```

## 7. 반응형 웹으로의 방향 전환

초기에는 Windows 데스크톱 앱으로 구현했으나, 교수님 피드백을 반영하여 브라우저 기반 반응형 웹으로 방향을 변경했습니다. 데스크톱 전용 실행 코드, 창 제어 기능과 전용 의존성은 제거했습니다.

PC에서는 사이드바를 아이콘만 남기도록 접거나 메뉴 이름까지 펼칠 수 있습니다. 모바일에서는 상단 버튼으로 메뉴를 열고 닫으며, 콘텐츠·폼·팝업을 좁은 화면에 맞춰 배치합니다. 이러한 방식으로 별도 사용자 앱 설치 없이 접근하는 서비스를 목표로 합니다.

## 8. 향후 개발 계획

아래 항목은 현재 완료된 기능이 아닌 후속 개발 목표입니다.

1. **학사일정 검색 연결:** 대학 공식 출처에서 일정을 확보하고 확인·수정 후 반영하는 흐름을 구현합니다.
2. **추천 고도화:** 관심 분야 적합도, 준비기간, 학사일정 충돌을 판단하는 규칙을 정리하고 실제 정보와 연결합니다.
3. **LLM 연결:** 비정형 학사일정 구조화와 대화형 안내에 활용하되, 추출 결과 검증과 사용자 확인 단계를 둡니다.
4. **알림 구현:** 실제 발송 채널과 웹을 닫은 이후의 알림 제공 방식을 결정합니다.
5. **서비스 운영 준비:** 사용자 계정·기기 간 동기화 필요 여부, 운영 서버, HTTPS와 배포 방식을 결정합니다.
6. **정보 범위 확대:** 국가공인 민간자격과 실제 공모전 정보 연동을 검토합니다.

## 9. 실행 및 검증

프로젝트의 Python 가상환경과 의존성이 준비되어 있다면 `start-web.cmd`를 실행한 뒤 브라우저에서 `http://127.0.0.1:8000`에 접속합니다. 설치와 상세 실행 방법은 [README](../README.md)를 참고하세요. 현재 서버는 로컬 개발·시연용이며 공개 서비스 배포는 아직 진행하지 않았습니다.

데스크톱 코드 정리 후 웹 단위 테스트 18개와 반응형·자격증 화면 검증을 통과했습니다. 반응형 검증은 Edge에서 320~1440px의 7가지 화면 너비를 대상으로 수행했으며, 실제 모바일 기기와 Safari 검증은 추가로 필요합니다.

## 10. 발표용 소개 문장

> SpecSignal은 대학생이 자격증과 대외활동을 탐색하고 자신의 학사일정과 준비 가능 시간을 고려해 도전 계획을 세우도록 돕는 반응형 웹 프로젝트입니다. 현재 공식 API 기반 자격증 탐색과 개인 캘린더를 구현했으며, 추천·학사일정·알림의 사용자 흐름을 데모로 구성했습니다. 앞으로 공식 학사일정 검색과 개인화 추천을 연결하여 정보 탐색부터 일정 관리까지 지원하는 것을 목표로 합니다.

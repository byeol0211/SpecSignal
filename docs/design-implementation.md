- CSS 변수에 사이드바 `#94a5cf`, 상세 배경 `#a9b6d7`, 버튼 `#334176` 등의 색상을 정의했습니다.
- 시안의 겹친 카드·필터·사이드바 레이어는 하나로 통합했습니다. 고정 좌표 대신 CSS Grid/Flex를 사용합니다.

- 시안의 임시 이름과 반복 설명은 하드코딩하지 않습니다. 프로필 이름 입력, 실제 종목명·분류·상세·일정으로 대체합니다.
- 프로필 관리/탐색/자격증 메뉴는 작동합니다. 시안의 라디오 메뉴는 서비스 목적에 맞춰 일정 알림으로 바꾸고 준비 중으로 표시했습니다. 공모전과 맞춤형 추천도 준비 중입니다.
- 시안의 Code Connect `X`는 로컬에 대응 컴포넌트나 React 의존성이 없으므로 접근 가능한 HTML 닫기 버튼으로 구현했습니다.
- 상세 응답은 텍스트로만 표시하며 화면에서 연속 빈 줄을 두 줄로 정리합니다. 원문 저장 데이터는 바꾸지 않습니다.

## 반응형 웹 전환 (2026-09-29)

교수님 피드백에 따라 PC·태블릿·모바일 브라우저에서 사용할 수 있도록 기존 UI를 변경했습니다. 앞선 데스크톱 구현 기록보다 이 변경 사항을 우선 적용합니다. 기존 연보라색 테마와 SVG를 재사용했으며 Figma 원본 파일 자체는 수정하지 않았습니다.

- 상단의 데스크톱 미리보기 표기를 웹으로 변경했습니다.
- 760px 이하에서는 사이드바를 접고 상단 메뉴 버튼으로 여는 방식을 적용했습니다. 메뉴 선택 시 닫힘, Escape 닫기, aria-expanded와 키보드 초점 처리를 추가했습니다.
- 고정된 앱 내부 스크롤에서 웹 문서 전체 스크롤로 변경했습니다.
- 모바일에서는 홈·프로필·채팅 보조 영역을 한 열로 배치하고, 검색 필터를 세로로 표시합니다. 420px 이하에서는 공식 자격증 카드도 한 열로 표시합니다.
- 캘린더 7열은 유지하고 날짜 셀 크기를 조정했습니다. 날짜별 상세 목록에서 전체 일정을 확인할 수 있습니다.
- 일정 등록·상세 팝업, 알림 패널, 토스트의 크기를 화면 안으로 제한했습니다. 긴 팝업은 내부 스크롤로 끝까지 접근합니다.
- 모바일 버튼과 폼의 기본 높이를 44px 이상으로 조정했습니다. 달력과 스위치 등 일부 전용 컨트롤은 자체 크기를 유지합니다.
